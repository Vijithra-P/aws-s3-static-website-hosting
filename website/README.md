# AWS S3 Static Website Hosting

## Project Overview

This project demonstrates how to host a static website using Amazon S3.

## Technologies Used

- AWS S3
- HTML
- CSS

## What This Project Does

- Creates an S3 bucket
- Uploads static website files (HTML/CSS)
- Configures S3 static website hosting
- Accesses the website using an S3 website endpoint

## What is Static Website Hosting?

Static website hosting in S3 allows an S3 bucket to serve web pages (HTML, CSS, JavaScript) directly through a web endpoint, treating the bucket as a website instead of just storage.

## Static vs Dynamic Website

### Static Website
- Content is fixed and does not change based on user interaction
- No backend server or database involved
- Example: portfolio websites, simple landing pages

### Dynamic Website
- Content is generated based on user requests
- Uses backend servers and databases
- Example: Amazon, Instagram, banking applications
